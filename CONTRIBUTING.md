# Contributing to Awesome AI Decision Matrix

Thank you for your interest in contributing to **Awesome AI Decision Matrix**! We welcome submissions from creators, software engineers, and researchers.

## 📋 Inclusion Criteria

To maintain our repository's reputation on **[sindresorhus/awesome](https://github.com/sindresorhus/awesome)** and developer curation lists, all tools must satisfy these criteria:

1. **Active & Accessible:** The tool must have a functional production web app or API (no waitlist-only vaporware).
2. **Transparent Pricing:** Clearly defined pricing tiers (Free, Freemium, or Paid) with starting costs listed.
3. **Reproducible Value:** Must solve a discrete workflow problem without relying on deceptive dark patterns.
4. **Canonical Metadata:** Please submit your tool to our verification queue at [https://aidecisiontool.com/submit](https://aidecisiontool.com/submit?utm_source=github&utm_medium=awesome-matrix) so technical specifications can be verified automatically.

## 🛠️ How to Propose a Change

1. Fork this repository.
2. Create a new branch: `git checkout -b feature/add-my-tool`.
3. Add your tool to the relevant section following the table format:
   `| [Tool Name](https://aidecisiontool.com/tools/slug?utm_source=github&utm_medium=awesome-matrix) | Pricing | Key Edge | [vs Competitor](https://aidecisiontool.com/compare/slug1-vs-slug2?utm_source=github&utm_medium=awesome-matrix) | [Alternatives](https://aidecisiontool.com/alternatives/slug?utm_source=github&utm_medium=awesome-matrix) |`
4. Commit your changes: `git commit -m "feat(matrix): add Tool Name"`.
5. Push to your branch and open a Pull Request.
